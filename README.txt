MONSTER-INSPIRED JEE TRACKER — VERSION 2

START:
1. Extract this ZIP into a folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Enter your name and JEE Main date, then click "Enter workspace".
4. Use the left navigation to open each section.

IMPORTANT:
- All controls are interactive: navigation, date selection, adding tasks, checkboxes, timers, progress, and backup tools.
- Your data is saved in this browser on this device using local storage.
- Export a JSON backup in Settings before clearing browser data or changing devices.
- This is a static website. You can publish the folder on GitHub Pages; no Python server is required.
- JEE Advanced date is editable in Settings. Set the official date when announced.
- The mock test completion action records its planned duration as study time on the scheduled date.
- Image attachment in Test Analysis currently records the filename only; use a song title/link or notes as your reference.
